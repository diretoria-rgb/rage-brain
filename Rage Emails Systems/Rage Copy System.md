

### Versão 1.0

## Objetivo

O Rage Copy System transforma a identidade da Rage em textos consistentes para todos os pontos de contato com o cliente.

Este documento não substitui o Tom de Voz da marca. Ele explica como aplicar esse tom em diferentes formatos de comunicação.

---

# 1. Princípio Fundamental

A Rage nunca escreve para vender roupas.

A Rage escreve para fortalecer pessoas que escolheram uma vida difícil.

A roupa é consequência.

O propósito vem antes do produto.

---

# 2. O papel da copy

Toda comunicação deve cumprir pelo menos uma destas funções:

- Inspirar.
    
- Educar.
    
- Gerar confiança.
    
- Mostrar competência.
    
- Facilitar uma decisão.
    
- Convidar para fazer parte da comunidade.
    

Vender é consequência dessas etapas.

---

# 3. Pirâmide da Comunicação

Sempre seguir esta ordem:

1. Propósito.
    
2. Pessoa.
    
3. Problema.
    
4. Solução.
    
5. Produto.
    

Nunca começar pelo produto.

---

# 4. O Produto nunca é o Herói

O herói sempre é o atleta.

A Rage apenas fornece as ferramentas.

Nunca escrever:

"Esta camiseta melhora seu treino."

Preferir:

"Você treina. Nós garantimos que sua roupa acompanhe."

---

# 5. Simplicidade

Escrever pouco.

Cada frase deve existir por um motivo.

Eliminar palavras que não acrescentam significado.

---

# 6. Clareza

Escrever como alguém que conversa depois de um treino.

Sem linguagem técnica desnecessária.

Sem palavras difíceis apenas para parecer sofisticado.

---

# 7. Honestidade

Nunca prometer resultados.

Nunca exagerar benefícios.

Nunca usar frases como:

- Melhor do mercado.
    
- Revolucionário.
    
- Tecnologia exclusiva.
    
- Performance garantida.
    

Preferir fatos.

---

# 8. O Produto sempre resolve um problema

Toda peça precisa responder:

"O que ela resolve?"

Nunca apenas:

"O que ela possui?"

---

# 9. Mostrar antes de explicar

Sempre que possível:

Imagem primeiro.

Texto depois.

O texto apenas reforça o que a imagem já comunica.

---

# 10. Headlines

Curtas.

Fortes.

Até seis palavras.

Exemplos:

Hard by Choice.

Built to Overcome.

Escolha sua ferramenta.

Feito para treinar.

Treine. Repita. Evolua.

---

# 11. Corpo do texto

Máximo recomendado:

40 a 80 palavras.

Um único assunto por email.

---

# 12. Chamadas para ação (CTA)

Os CTAs devem parecer um próximo passo natural.

Evitar:

Comprar agora.

Clique aqui.

Aproveite.

Preferir:

Conhecer a coleção.

Escolher meu equipamento.

Ver os detalhes.

Encontrar meu tamanho.

Montar meu kit.

---

# 13. Emoções que a Rage desperta

Priorizar:

Disciplina.

Confiança.

Pertencimento.

Constância.

Superação.

Competência.

Calma.

Evitar:

Ansiedade.

Medo.

Urgência exagerada.

Pressão.

Vergonha.

---

# 14. O que nunca fazemos

Não gritamos.

Não imploramos.

Não exageramos.

Não manipulamos.

Não escrevemos apenas para vender.

---

# 15. Antes de publicar qualquer texto

Perguntar:

✔ Parece que foi escrito pela Rage?

✔ Parece útil?

✔ Está simples?

✔ Está honesto?

✔ O atleta é o protagonista?

✔ A roupa é consequência?

Se qualquer resposta for "não", reescrever.

---

# Regra Final

Toda copy deve deixar o leitor com a sensação de que escolheu treinar.

Nunca apenas que escolheu comprar.
