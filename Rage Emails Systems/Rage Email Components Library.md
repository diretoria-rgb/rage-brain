

### Versão 1.0

## Objetivo

Organizar todos os blocos reutilizáveis utilizados na construção dos emails da Rage.

Os componentes não são emails completos.

São módulos que podem ser combinados para criar diferentes comunicações, mantendo consistência visual, estratégica e operacional.

---

# Component 01 — Hero

## Objetivo

- Headline.
    
- Subheadline (opcional).
    
- CTA.

# Component 11 — CTA Final

## Objetivo

Encerrar o email conduzindo o cliente para a próxima ação.

Exemplos:

- Conhecer a coleção.
    
- Escolher meu equipamento.
    
- Participar do desafio.
    
- Ver os detalhes.
    
- Encontrar meu tamanho.
    

Todo email deve possuir apenas um CTA principal.

---

# Component 12 — Rodapé

## Objetivo

Padronizar o encerramento de todos os emails.

Elementos obrigatórios:

- Logo Rage.
    
- Instagram.
    
- Site.
    
- Contato.
    
- Cancelar inscrição.
    

Este componente deve permanecer igual em todas as comunicações.

---

# Regras Gerais

- Cada email deve utilizar apenas os componentes necessários.
    
- Evitar excesso de módulos em uma única comunicação.
    
- Um email deve desenvolver apenas uma ideia principal.
    
- Sempre priorizar clareza, simplicidade e objetividade.
    

---

# Fluxo de Construção

Todo novo email deverá seguir a seguinte sequência:

1. Definir o objetivo.
    
2. Preencher o Rage Email Builder.
    
3. Selecionar os componentes necessários.
    
4. Produzir o conteúdo.
    
5. Montar o layout.
    
6. Implementar.
    
7. Testar.
    
8. Publicar.
